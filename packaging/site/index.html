qrow

Query rows in tables, documents and databases — from the terminal or through an AI assistant.

CSV, TSV, JSON, JSONL, YAML, TOML, Markdown, Parquet, Arrow, Excel, SQLite and DuckDB. Large CSV, Parquet, Arrow and JSONL files are read as a stream, not loaded whole.

qrow sales.csv
regionproductunitsrevenue
NorthLamp1204 680.00
NorthDesk349 146.00
SouthChair21012 390.00
SouthLamp883 432.00
WestDesk5113 719.00

row 3 of 5

Install

Cargo

cargo install qrow

Homebrew (macOS, Linux)

brew tap denisotree/qrow
brew install qrow

Arch Linux (AUR)

yay -S qrow        # or qrow-bin for the pre-built binary

Debian, Ubuntu (APT)

curl -fsSL https://qrow.dev/apt/qrow.gpg \
  | sudo tee /usr/share/keyrings/qrow.gpg > /dev/null
echo "deb [signed-by=/usr/share/keyrings/qrow.gpg] https://qrow.dev/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/qrow.list
sudo apt update && sudo apt install qrow

amd64 and arm64, Debian 12+ and Ubuntu 22.04+. Pre-built archives for Linux and macOS are on the releases page. Every install brings two commands: qrow and the short qrw.

AI assistants

Started with --mcp, qrow is an MCP server: the assistant sends operations and reads back computed numbers instead of estimating them. --mcp-write also lets it change rows in SQLite and DuckDB, always as a planned change shown before it runs.

Claude Code

claude mcp add -s user qrow -- qrow --mcp

Clients configured with JSON

{
  "mcpServers": {
    "qrow": {
      "command": "/opt/homebrew/bin/qrow",
      "args": ["--mcp"]
    }
  }
}

Use the full path: a desktop app does not start from your shell and may not see your PATH. which qrow prints yours.

Coming from tuitab

qrow is tuitab under a new name, from version 0.12.0. The commands tuitab, ttab and ttb are now qrow and qrw, and the MCP tools are qrow_*.

Cargo

cargo uninstall tuitab && cargo install qrow

Homebrew

brew update && brew upgrade replaces tuitab with qrow by itself.

AUR

Install qrow or qrow-bin; pacman offers to replace the old package.

APT

The old repository stays at 0.11.1. Remove it, then add the new one as in Install above; installing qrow removes tuitab.

sudo rm /etc/apt/sources.list.d/tuitab.list /usr/share/keyrings/tuitab.gpg

MCP

claude mcp remove -s user tuitab
claude mcp add -s user qrow -- qrow --mcp

Keep --mcp-write if you had it. Permission rules follow the server's name: mcp__tuitab__tuitab_* becomes mcp__qrow__qrow_*. In a JSON config, rename the key and the command to qrow.
